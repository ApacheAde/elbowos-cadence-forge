# Cadence Forge

Full-colour Python 3 neon **rhythm-tap** arcade for [ElbowOS](https://x.com/ElbowOS).

Hit falling notes on four lanes (`D F J K`) as they reach the strike bar. Combos score PERFECT / GREAT / OK.

## Play

```bash
pip install -r requirements.txt
python3 cadence_forge.py
```

Keys: **D F J K** tap lanes · **R** restart · **ESC** quit.

## Autoplay reel (9:16)

```bash
python3 cadence_forge.py --record
# or: ELBOWOS_RECORD=1 python3 cadence_forge.py
```

Writes a 15s 1080×1920 H.264 MP4 (`CADENCE_FORGE_ElbowOS.mp4`).
